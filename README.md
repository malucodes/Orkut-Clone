# ✦ Orkut Clone | Arqueologia Digital & Nostalgia

![Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)
![Aesthetics](https://img.shields.io/badge/Aesthetics-Y2K%20%2F%202000s-blue)

Este projeto é um tributo ao **Orkut**, a rede social que definiu uma era na internet brasileira. O objetivo foi recriar a interface icônica e a experiência de usuário que marcou os anos 2000, unindo design clássico com tecnologias modernas de desenvolvimento web.

---

## ✧ Sobre o Projeto

Como parte dos meus estudos sobre a história da tecnologia e estéticas digitais, decidi reconstruir o layout do Orkut para entender a arquitetura visual das redes sociais da época. O projeto foca na fidelidade visual e na funcionalidade das seções mais queridas pelos usuários.

### ⊹ Funcionalidades Recriadas
* **Perfil do Usuário:** Foto de perfil, informações básicas e o icônico gráfico de "Sorte", "Legal".
* **Scrapbook (Recados):** A clássica área para deixar mensagens públicas.
* **Comunidades:** Interface lateral exibindo as comunidades que o usuário participa.
* **Depoimentos:** Aquela seção onde o "só aceita se for ler" era a regra!

---

## ✶ Tecnologias Utilizadas

Para este projeto, utilizei um stack focado em produtividade e componentização:

* **JavaScript** Para a construção da interface interativa.
* **Styled Components:** Para estilizar os elementos mantendo a fidelidade às cores e bordas originais.
* **JSON:** Para simular o banco de dados de amigos e recados.
* **HTML5 & CSS3:** Garantindo que a estrutura respeitasse a identidade visual clássica.
